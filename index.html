Cách đo WER: không có transcript gốc đi kèm 4 case này, nên 2_target_groundtruth.wav (giọng mục tiêu sạch, chưa trộn nhiễu, chưa qua TSE) được đưa qua whisper tiny.en để lấy transcript dùng làm tham chiếu. WER mixture/TSE là so với transcript đó — một proxy hợp lý để xem TSE cải thiện bao nhiêu so với mixture thô, không phải một con số WER chuẩn tuyệt đối. Chi tiết: README của repo này.
Model: causal TF-GridNet rút gọn (sliding-window attention, LSTM nhân quả) — input 16kHz mono + speaker embedding 256 chiều (Resemblyzer d-vector), output 16kHz mono chỉ chứa giọng mục tiêu. Đo trên Libri2Mix test mix_both (6000 câu, nhiễu WHAM): SI-SDRi +8.86 dB, PESQ 1.45, STOI 0.80. Mã nguồn & dữ liệu test đầy đủ trong repo này.
